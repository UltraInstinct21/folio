the whole point,

small on purpose

Folio keeps every feature you need for a nice reading session and leaves out everything else. No services, no update daemons, no background jobs of any kind.

2mb

takes almost no room

The linux installer is about 2 mb and the binary is 5 mb. Small enough to run from a usb stick or keep every release around forever.

0 cloud

no accounts, no sync

Your library never leaves the machine. There is nothing to log into and nothing to leak.

json

readable state

Your whole library is one json file you can open, back up or diff. Covers and books sit next to it. Delete the folder to reset.

fast

opens instantly

No framework, no bundler, no runtime beyond the system webview. The frontend is a handful of plain html, css and js files.

and inside,

a quiet reading room

Paginated pages that turn with a click, the arrow keys, space or the mouse wheel. Resume exactly where you left off. Pick a theme, pick a font size, read at night without burning your eyes.

✦

four highlight colors

Select text to highlight in one of four colors or copy it. Click a highlight later to remove it.

≡

table of contents

One key opens the contents panel. Jump to any chapter, close it, keep reading.

◑

three themes

Light, sepia and dark, applied live to every last margin of the page. No stale corners left behind.

↻

picks up where you left

Every book remembers its page. Drop epubs straight onto the window or use the picker.
